# Data-analysit-Project-1
Customer Churn Analysis for Telecom Industry

1. Project Description

This project predicts whether a telecom customer is at risk of leaving the company.

2. Objective

To identify customers who may leave and suggest ways to retain them.

3. Technologies Used

- Python
- Pydroid 3

4. Features

- Enter customer call duration.
- Enter the number of complaints.
- Enter recharge frequency.
- Identify at-risk customers.
- Suggest special recharge plans and loyalty rewards.

5. How to Run

1. Open Pydroid 3.
2. Create a new Python file.
3. Copy the project code.
4. Save the file as "churn_analysis.py".
5. Click the Run button.
6. Enter the customer details.

6. Sample Output

CUSTOMER CHURN ANALYSIS
-----------------------
Enter call duration: 50
Enter number of complaints: 3
Enter recharge frequency: 1
Customer is At Risk
Offer a special recharge plan

7. Conclusion

This project demonstrates a simple way to identify customers who may leave a telecom company and suggest actions to improve customer retention.
